# FileBrownie

FileBrownie is a local-first system for searching and organizing personal documents. Its first milestone is answering a question about a document field from local files while selecting the current version and showing the source.

The project scope, architecture, and development sequence are in [the project plan](docs/filebrownie_project.md).

## Repository safety

Keep real documents, extracted data, credentials, and other personal information out of Git. Use synthetic examples in committed files.
